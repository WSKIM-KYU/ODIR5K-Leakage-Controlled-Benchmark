# ODIR-5K Leakage-Controlled Benchmark

This repository contains the code and supporting materials for:

"Label Granularity and Evaluation Design in ODIR-5K: A Leakage-Controlled Benchmark with External Validation for Fundus Disease Classification"

Authors:
Ha Rang Cho and Woong Sik Kim
Konyang University, Republic of Korea

## Overview

This repository provides the materials required to reproduce the
experiments reported in the manuscript.

The study investigates the effects of label granularity, data splitting,
training-set evaluation, fellow-eye leakage, input resolution, and
external validation on fundus disease classification using ODIR-5K.

## Contents

- Patient-level split files
- Five-fold cross-validation assignments
- Eye-level label dictionary
- RFMiD label-mapping protocol
- Training and evaluation code
- Out-of-fold and test predictions
- Experiment configuration files
